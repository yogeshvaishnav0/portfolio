# Yogesh Vaishnav Portfolio

A responsive personal portfolio for Yogesh Vaishnav, a Computer Science student and cybersecurity enthusiast based in Vadodara, Gujarat. The site presents technical projects, security training, development skills, digital creation work, certifications, education, and contact links in a dark cybersecurity-inspired interface.

## Features

- Responsive layout for desktop and mobile screens
- Sticky navigation with a mobile menu
- Hero section with profile image, introduction, and quick stats
- About section covering education, location, and languages
- Featured projects:
	- **SecureStack**: a Flask and Python cybersecurity toolkit
	- **BrainSparkz**: an AI-powered learning and gamification platform
- Skills grouped by cybersecurity, development, systems, creative work, strengths, and tools
- Digital creator metrics and YouTube link
- Quick Heal Academy certification links
- Education and milestone timeline
- Contact links for email, phone, LinkedIn, and GitHub

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Inter and JetBrains Mono

## Project Structure

```text
.
├── index.html     # Portfolio content and page structure
├── style.css      # Layout, responsive styles, and visual design
├── script.js      # Mobile navigation behavior
├── profile.png    # Hero profile image
└── README.md      # Project documentation
```

## Run Locally

No build tools or dependencies are required.

1. Clone or download the project.
2. Open `index.html` directly in a browser.

For a local development server, open the folder in VS Code and use the Live Server extension, or run any static file server from the project directory.

## Customize

- Edit portfolio text, links, projects, and milestones in `index.html`.
- Update colors, layout, typography, and responsive behavior in `style.css`.
- Update navigation behavior in `script.js`.
- Replace `profile.png` with another image using the same filename, or update the image path in `index.html`.
